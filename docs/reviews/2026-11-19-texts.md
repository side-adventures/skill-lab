# Texts overview (2026-11-19)

Working document for a pass over all player-facing texts. Part 1 lists the kinds of text and where they show.
Part 2 is a **draft** of guidelines (to agree on, then move into CLAUDE.md). Part 3 is the current text per kind,
with what doesn't fit yet. Nothing has been changed in the code.

## 1. What texts there are

| Text | Field / source | Where it shows |
|---|---|---|
| Name | `name` | home card, top bar, share text |
| Tagline | `tagline` | home card (2 lines max), rules screen (as headline), "?" overlay |
| Skill line | `skill` → "Tests …" | rules screen under the tagline |
| How to play | `howTo[]` | rules screen + "?" overlay |
| Score | `scoring[]` | rules screen + "?" overlay |
| Duration | `durationHint` | home card, rules info row |
| Score label | `scoreLabel` | result screen, above the big score |
| Score format | `formatScore` | result, stats, share ("312 ms", "7 digits") |
| Result stats | `details.stats / extra / chips` labels | result screen, stats page |
| No-score message | `failed: '…'` | result screen instead of a score |
| Info row | `<GameInfo left middle right>` | above the play area while playing |
| Play-area texts | hints, round results, end moments ("Out of lives") | inside the play area |
| Answer buttons | `AnswerButtons` labels + key hints | play area |

## 2. Draft guidelines

**General**
- Say "click" for mouse input; name keys as keys (Enter, ← / →).
- One word per thing, site-wide: *round* (not trial / item), *level* only where difficulty steps up, *mistake* in
  general ("a wrong tile / wrong click" when it's specific), *lives*, *run* vs *test* → **open: pick one** for "ends
  the …".
- Numbers: digits ("3 lives", "5 rounds"). Time: whole durations spelled out in rules ("45 seconds"), short values with
  `s` / `ms` ("0.8 s", "1 s"). **Open: confirm.**
- Real minus `−`, `×`, `÷`; "3×3" for grids; " / " with spaces between alternatives (← / →).
- No contractions ("does not").

**Tagline** — one sentence, says what you *do*, newcomer-proof, playful is fine but no promise the test doesn't keep.
Fits 2 lines on the home card (≈ 60 characters). **Open: one form** (imperative "Pick the ink color, not the word."
vs question "How fast can you tap?") or free choice?

**Skill line** — a lowercase noun phrase, 2–4 words, the construct measured ("reaction speed", "working memory").
No clauses ("how much you take in …") or gerund sentences ("keeping time in your head").

**How to play** — 2–5 short lines, in this order:
1. what you see, 2. what you do (incl. input options: "type it on your keyboard, or click it on the keypad"),
3. how the run goes (rounds / time limit / what gets harder), 4. lives / mistakes / fail conditions.
Fixed sentence templates for the recurring lines:
- Time limit: "You have 60 seconds: answer as many as you can."
- Rounds: "5 rounds, …"
- Lives: "You have N lives: a <wrong tile / mistake> costs one, and you play the <round / level> again with a new
  <pattern / layout>. Out of lives ends the test."
- One-mistake: "One mistake ends the test."
- No score: "… ends the test without a score."
No tips, no trivia (keyboard advantage is the one allowed tip).

**Score** — 1–2 lines. Line 1 starts with "Your …" and says the score in its unit and why that measure
("Your median … so one slow round does not spoil it"). Line 2 only for penalties or a result stat that needs
explaining: "The result also shows …". Shared templates:
- "Correct answers minus wrong answers, so guessing does not pay off."
- Time penalties: "Each wrong click adds 1 s."

**Duration** — "~1 min" / "~2 min" for variable runs; exact "30 s", "45 s", "60 s" for a fixed clock.

**Score label** — the measure, capitalized, no formula unless needed: "Median reaction time", "Longest number",
"Total time", "Average accuracy". Same measure → same label.

**Result stats** — short labels (1–3 words), same word for the same stat: "Avg …", "Fastest / Slowest",
"Closest / Furthest off", "Tendency", "Wrong clicks".

**No-score message** — "<what was missing> — try again!" ("No answers — try again!").

Mix: 17 imperatives, 6 questions, 3 fragments.

### Skill lines ("Tests …")
Fine: reaction speed · selective attention · mental arithmetic · spatial memory · recognition memory · working memory
(×2: N-Back, Backward Span) · impulse control · visual search · spatial reasoning · processing speed · visual working
memory · clicking speed · hand–eye tracking · aim and speed.

Don't fit the noun-phrase form:
- Time Estimation: "keeping time in your head"
- Sequence Memory: "remembering a growing sequence of positions" (long)
- Flash Order: "how much you take in at a glance"
- Quick Count: "estimating amounts at a glance"
- Hit the Line: "timing a moving target"
- Line Tracing: "fast, precise movement"
- Geometry / Split Half: "judging shapes and angles by eye" / "judging area by eye"
- Number Memory: "short-term memory for numbers" vs Pattern Memory "short-term visual memory" (ok, but pair them)
- Go / No-Go: the 11-13 audit flagged "impulse control" as reading clinical.

### How to play — mismatches
- **Input options missing:** Quick Count ("type how many you think you saw") and Number Memory ("Type it back from
  memory") both have a keypad but don't say so. Quick Maths and Backward Span use the full line.
- **Keys mentioned inconsistently:** Split Half ("The ← / → keys also move it"), Change Detection ("(or ↑ / ↓)"),
  Symbol Code (own line); Stroop, Mental Rotation, Word Memory, N-Back, Go / No-Go don't mention keys (buttons show
  them). **Open:** mention keys in rules only for typing / when the keyboard is recommended, since buttons show their
  keys?
- **Lives lines, 7 wordings:**
  - Pattern Memory: "One wrong click fails the level: you lose one of your 3 lives and retry with a new pattern. Out of
    lives ends the test."
  - Number Memory: "… a mistake costs one, and you get a new number of the same length."
  - Number Order: "… a wrong tile costs one, and you play that round again with new positions."
  - Flash Order: "… a wrong tile costs one, and you try the same flash again with new positions."
  - Word Memory: "… every wrong answer costs one." (what happens after isn't said, nor that 0 ends it)
  - Backward Span: "… a mistake costs one." (doesn't say you replay the same length)
  - N-Back: "Every mistake beyond 2 costs one of your 4 lives, and you play the level again. Out of lives ends the test."
  - Only 2 of 7 say "Out of lives ends the test".
- **Time-limit lines, 4 wordings:** "You have 45 seconds: answer as many as you can." (Stroop, Symbol Code) ·
  "You have 60 seconds." (Mental Rotation) · "You have 30 seconds." (Aim Trainer) · "The test lasts 30 seconds."
  (Circle Chase). Quick Maths has its 60 s only in Score ("in 60 seconds"), not in How to play.
- **Round count:** Reaction says "5 rounds" only in Score; Geometry says "8 short tasks" (task vs round).
- **"test" vs "run":** "ends the test" (most), "ends the run without a score" (Line Tracing).
- **Trivia:** Flash Order's "Fun fact: … Ayumu …" line sits in How to play; it's not a rule.
- **Long lines:** Change Detection line 3, N-Back lines 4–5, Geometry line 1, Advent line 2.
- **Answer button names:** in capitals where named (SEEN / NEW, MATCH, SAME / CHANGED); Mental Rotation doesn't
  name its SAME / MIRRORED buttons.

### Score — mismatches
- Openings mix "Your …" (Reaction, Time Est., Quick Count, Go / No-Go, Hit the Line, Line Tracing, Advent, Odd One Out,
  Geometry, Split Half, Tap Speed, N-Back) and "The …" (Pattern, Number Memory, Sequence, Number Order, Flash Order,
  Word Memory, Quick Maths, Circle Chase, Backward Span) and others ("How many shapes …", "Correct answers minus …",
  "A hit in the red center …").
- "Your result also shows" (Stroop) vs "The result also shows" (Advent, Odd One Out, Symbol Code).
- Penalty wording: "Each wrong click adds 1 s" (Odd One Out) vs "plus 1 s for each wrong door" (Advent).
- N-Back's one line is hard to read (level × 100, lives bonus, example in one sentence).
- Score lines that explain *why* (median, correct − wrong) vs most that don't — fine, only where it helps.

### Duration
"~1 min", "~2 min", "~3 min", "30 s", "45 s", "60 s", "10 s", "~30 s" (Line Tracing). Consistent; Line Tracing's
"~" is right (variable).

### Score labels
- "Longest number" / "Longest sequence" / **"Longest reversed"** (Backward Span: the odd one).
- "Most tiles" (Pattern Memory, Number Order) — fine.
- "Correct answers" for Quick Maths (shows "12 correct") and Word Memory (shows "12 words").
- "Total time" ×3 vs "Time" (Line Tracing) — fine (single time).
- Averages: "Average error" (Time Est.), "Average timing error" (Hit the Line), "Average accuracy" (Quick Count,
  Geometry), "Average points" (Split Half) — three "how close" estimation tests in three units (%, %, pts).
- Formulas in labels: "Points (correct − wrong)" ×3, "Points (level × 100 + lives bonus)".

### Result stat labels (spot check)
- Average: "Average" (Reaction), "Avg reaction", "Avg per target", "Avg time per tile", "Avg per level",
  "Avg per answer", "Avg time per click", "Avg off by", "Average miss", "Avg off-center".
- Mistakes: "Wrong clicks", "Misses", "Wrong doors, round 1", "Missed greens".
- Where it ended: "Failed with", "Failed at length", "Missed at", "Out of lives at", "Ended at".
- Extremes: "Fastest / Slowest", "Closest / Furthest off", "Biggest miss", "Best task / Weakest task".

### No-score messages
"No clicks — try again!" · "No answers — try again!" · "Not even the first round — try again!" ·
"Too many early clicks" (no "try again") · "Off the line at 63 %" (no "try again").

### Not covered yet
Info-row middle texts and play-area hints per test (e.g. "Type it, then Enter", "Rotated, or mirrored?", "Click the
color of the ink", "Look at the board"). Worth a pass in the browser once the rules texts are settled.
